# Local data only

The directory placeholders support project layout checks. No dataset is distributed. Obtain CBIS-DDSM and CMMD independently under their official access/citation terms; see `docs/DATA_AND_LICENSING.md`. Full reproduction requires the original authorised metadata, split/cohort manifests and hash-bound provenance, not merely a fresh dataset download. Raw DICOMs, clinical source tables, masks and caches belong locally and must not be dragged into a browser upload.
