# Environment and dependencies

The current dependency pins were read from installed package metadata, without importing or executing model code. The observed local interpreter is Python 3.12.10 on Windows; the saved audit records CPU-only local execution. These pins are an environment snapshot, not a verified clean-install or cross-platform guarantee. Transitive dependencies are not fully locked. No packages were installed during submission preparation. A read-only check of the installed environment reported `No broken requirements found`; this does not establish fresh-install compatibility.

`requirements.txt` covers TensorFlow/Keras models, NumPy arrays, pandas tables, scikit-learn/SciPy metrics, matplotlib figures, pydicom decoding, OpenCV/Pillow image handling, PyYAML configuration, Streamlit and ReportLab PDF export. `requirements-dev.txt` adds pytest and includes the metadata requirements because workbook fixtures need openpyxl. `requirements-metadata.txt` adds openpyxl for CMMD XLSX parsing. The original unpinned tqdm entry was omitted because no source/test import uses it; it may still be resolved transitively. No codec plugin is claimed to support every compressed DICOM encoding.

Historical training environments are recorded separately in [historical_experiment_environments.json](historical_experiment_environments.json), extracted from frozen run metadata. Transfer-model runs used a Linux GPU environment with Python 3.13.15, TensorFlow 2.20.0, Keras 3.13.2 and NumPy 2.1.3. The metadata does not identify a GPU model. Do not describe the current Windows environment as the original training environment. GPU availability and numerical equivalence on another platform remain unverified.

A future clean-install acceptance check should create a new environment, install these files, run `python -m pip check`, run the tests, restore the approved private runtime files, and verify Streamlit manually. Some synthetic tests construct/train small test models; none were executed during this preparation. Scientific cohort evaluation is separate and must not be invoked merely to test installation.
