# Submission scope and remaining acceptance

Included: unmodified Python source/tests, configuration and hash anchors, selected frozen run configuration/metadata/history/aggregate metrics, aggregate tables and SVG charts, dependency specifications and public documentation. No code behaviour or scientific results were changed.

Excluded: development history, environments/caches, raw/processed medical data, ROI material, downloaded packages, checkpoints, patient-level clinical/prediction/header/cohort files, image-bearing review panels, draft reports, working instructions and internal planning notes. Existing package READMEs were superseded here by concise public docs because they contain local paths, archival commands and links to omitted private files. The originals remain unchanged in the development archive. Run metadata failing the personal-path/identifier screen was not copied.

The copy inventory maps each preserved file to its original relative path and SHA256. Public CSVs are aggregate saved values; they were not recalculated from images. A new README and supporting documentation describe this subset. Original evidence containing private details was excluded, not edited.

## Remaining manual acceptance

- [ ] Author/institution chooses the software licence and confirms required academic disclosures/citations.
- [ ] Confirm model/pretrained-weight redistribution rights and arrange authorised private runtime access or an approved public asset strategy.
- [ ] Verify installation in a new Python environment, including dependency resolution and full tests.
- [ ] Restore authorised original runtime files locally, then complete genuine browser acceptance and identifier-safe screenshots.
- [ ] Review all upload batches, inspect the public page and verify a downloaded fresh copy.

The historical audit recorded 537 tests passed and 333 deprecation warnings, with 13 targeted audit tests and a 145-file verifier PASS. None of these runs was repeated for submission preparation. The broader audit recorded 260 frozen bindings; neither that archive nor its 145-file verification scope is fully distributed here. A passing submission checksum check must not be presented as a new scientific audit.
